# SWYNEX Task 2 — Exploratory Data Analysis

## Objective
Explore the cleaned Iris dataset, calculate summary statistics, identify patterns, and visualize findings.

## Dataset
- File: `iris_cleaned.csv`
- Rows: 147
- Columns: 5
- Measurement columns: sepal length, sepal width, petal length, petal width (cm)
- Category column: species

## Tools
Python, pandas, matplotlib

## How to run
1. Install Python 3.
2. Install dependencies:
   `pip install pandas matplotlib`
3. Place `iris_cleaned.csv` in the same folder as `eda_analysis.py`.
4. Run:
   `python eda_analysis.py`

## Outputs
The analysis creates summary CSV files and charts in the `charts` folder.
